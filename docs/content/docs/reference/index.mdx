The rest of these docs say what a host does. These pages say what it reads and writes, key by key,
and each is rendered from the JSON Schema of the document, which is written from the Rust type that
parses it — so a page here cannot fall behind the code. Every page links to its schema, which is the
URL to point an editor at.
