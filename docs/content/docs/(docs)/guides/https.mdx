---
title: HTTPS
description: How hostnames are routed to apps, and where TLS is terminated.
---

`[proxy.http]` in `config.toml` defines the host's single HTTP listener. It routes each request,
by the hostname in the request, to the `httpPort` of the app that declares that hostname:

```json
"hostnames": [{ "hostname": "app-1.example.com", "kind": "platform" }]
```

`kind` is `platform` or `custom`. It is a label for whatever writes `desired.json`; both kinds
are routed the same way. An app that nothing needs to reach by name has an empty `hostnames`.

A request for a sleeping app wakes it. If `desired.json` names a hostname on a host with no
`[proxy.http]` section, the instance is reported `failed` with that reason. The
[reference](/docs/reference/config) lists every key under `[proxy]`.

## Behind an edge

The installer writes plain HTTP. Use this when something in front of the host terminates TLS:
Cloudflare, a load balancer, your own reverse proxy.

```toml
[proxy.http]
listen_address = "0.0.0.0"
port = 80
```

## TLS on the host

Add `[proxy.http.tls]` with a PEM certificate and key:

```toml
[proxy.http]
listen_address = "0.0.0.0"
port = 443

[proxy.http.tls]
certificate = "/etc/nibrunner/tls/origin.crt"
key = "/etc/nibrunner/tls/origin.key"
```

- **One certificate for the whole host.** There is no SNI selection. The certificate must cover
  every hostname of every app. In practice that means a wildcard, which matches one label:
  `app.example.com` but not `a.b.example.com`.
- **The daemon does not obtain certificates.** Use certbot or the edge for ACME and renewal. The
  files are read once, at startup. After renewing, run `systemctl restart nibrunnerd`. This does
  not stop any app.
- **One listener only.** You cannot run plain HTTP and TLS side by side. Nothing redirects
  between them, so two listeners would serve every app both ways.

## Client certificates

Add `[proxy.http.tls.client_ca]` to require a client certificate on every TLS handshake. Use this
when the origin's IP is discoverable and it must be reachable only through the edge:

```toml
[proxy.http.tls.client_ca]
certificate = "/etc/nibrunner/tls/origin-pull-ca.pem"
```

`certificate` is a PEM file holding every CA certificate to trust. Once enabled, you cannot reach
the host yourself without a client certificate, so enable it after the plain setup works.

<Callout title="Note">
  If the TLS handshake names one app (SNI) and the HTTP request names another (`Host`), the proxy
  answers `421`. This keeps apps that share a certificate separate.
</Callout>
